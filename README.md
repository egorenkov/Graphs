# Graph Algorithms Repository

## 📁 Описание проекта

Этот репозиторий содержит мои решения задач по теории графов с применением классических алгоритмов. Здесь представлены как теоретические основы, так и практические реализации на Python.

## 🗂 Структура репозитория

```
├── Graphs(csv)/               # CSV-файлы с данными графов
│   ├── metro2.csv        # Пример: схема метро в виде графа
│   ├── Graph1.csv     # Взвешенный граф
│   └── Graph2.csv
│
├── Graphs(solution)/          # Решения задач
│   ├── graph_exercise_1.ipynb # Задача 1
│   ├── graph_exercise_2.ipynb # Задача 2
│   ├── graph_exercise_3.ipynb # Задача 3
│   └── graph_exercise_4.ipynb # Задача 4
│
└── README.md                 # Этот файл
```

## 🔍 Реализованные алгоритмы

### 1. Алгоритмы обхода
- **Обход в ширину (BFS)**
- **Обход в глубину (DFS)**

### 2. Алгоритмы поиска кратчайших путей
- **Алгоритм Дейкстры** (для графов без отрицательных весов)
- **Алгоритм Флойда-Уоршелла** (для всех пар вершин)

### 3. Алгоритмы построения остовных деревьев
- **Алгоритм Краскала**

## 📊 Примеры данных

Все графы представлены в формате CSV:
- Вершины и ребра
- Взвешенные и невзвешенные графы
- Ориентированные и неориентированные графы

## 📝 Примечания

- Все решения сопровождаются комментариями
- Для визуализации некоторых графов используется библиотека `networkx`
- Данные находятся в папке `Graphs(csv)`
